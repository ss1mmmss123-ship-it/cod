# Folder Structure

- `contracts/` Solidity escrow contract for game staking and settlement.
- `backend/` Fastify API + websocket + game engine + escrow adapters.
- `frontend/` React/Tailwind client (lobby, table, wallet, profile, leaderboard).
- `docs/` Architecture, deployment, and security operational docs.
- `infra/` Container and orchestration templates.
- `scripts/` Local bootstrap helpers.
